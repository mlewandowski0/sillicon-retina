# Sillicon Retina Project Documentation

This work started on __Bangalore Neuromorphic Engineering Workshop 2025__, this project explores whether biologically‑plausible (“bio‑plausible”) event streams can improve downstream performance compared with conventional event‑camera output.

# Motivation
Silicon retina were one of the most pionnering wroks of Misha Mahowald and Carver Mead in the early 1990s. Modern event cameras extend this legacy by reporting only local brightness changes (polarity‑encoded ±1 events) instead of full RGB frames, yielding micro‑second latency and are designed so that they have enormous dynamic range. While these sensors are often labelled “neuromorphic,” their output is still a coarse abstraction of true retinal signalling. In this work, the research question is : 
- Are spatio-temporal events, generated by a retina model improves results on vision tasks, in comparision to regular temporal events ? 

# Goals 
- Design and prototype a silicon‑retina front‑end on a SCAMP‑5 Pixel Processor Array (PPA), enabling on‑sensor analogue/digital computation.
- Generate synthetic data via a CUDA pipeline that converts standard video into bio‑plausible event streams, based on a configurable retina model.
- Build a low‑cost hardware rig using a high‑speed STMicroelectronics global‑shutter sensor to approximate silicon‑retina output at hundreds of FPS.
- Benchmark the new event type on canonical event‑vision tasks—video reconstruction, recognition, and action classification—against standard DVS data.


# Results
- 11,000FPS (realistically 100s of FPS ) PPA prototype producing retina‑model events directly inside the sensor.
- Open‑source CUDA kernel for fast, GPU‑based generation of synthetic silicon‑retina events from any video input.
- Hardware‑in‑the‑loop simulator achieving high frame rates (>250 FPS) without the cost of true HDR event sensors.
